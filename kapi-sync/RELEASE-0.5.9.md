# 归账 NAS 0.5.9：安卓独立下载与 Pro 对接准备

- `/android/` 提供安装说明、本 NAS 下载与 GitHub 备用下载。只提供经过发行方签名清单和 APK 哈希核验的固定文件；未装入有效文件时保留 GitHub 入口，不影响账本服务。
- “连接与备份”增加安卓下载入口。手机可独立使用，NAS 为可选同步服务。
- 爱发电对接代码放在独立的发行方订单服务；API Token、订单签名私钥不放进用户镜像。新增订单、付款与退款不写账单、不改变现金余额。
- 安卓购买凭据可由 NAS 核验签名恢复；内测赠送、旧激活码与原有家庭继续保留。
- 新购买仍保持关闭，等待创作者账户、方案、私有 HTTPS 订单服务与真实付款／退款验收。

## 升级

保留原来的 data、tls、环境变量、端口、配对状态与家庭身份。先备份，再仅替换镜像版本。不要另建空 data 目录覆盖原目录，也不要重新导入家庭成员账单。

新镜像使用 GHCR 发布；Docker Hub 的 0.5.5 不会被冒充成新版本。以当前 GitHub Release 的验收结果为准。CI 容器验收不等同于已更新用户的 NAS。

本镜像打包 Android 0.1.172。0.5.8 是先前验证候选，未部署到用户 NAS；以本次实际容器检查和离线校验结果为准。
