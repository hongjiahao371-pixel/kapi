# 安卓独立分发与爱发电开通

## 下载和安装

1. 用户可直接从 GitHub Releases 下载安卓 APK，也可在已部署 NAS 的“连接与备份 → 下载安卓 App”打开 `/android/` 下载。无需先买 Pro，也不强制部署 NAS。
2. 仅使用归账官方签名的 `kapi.ledger` 包。系统询问时允许这次安装；不要关闭全局安全检测。
3. 已有 `kapi.ledger` 正式发行包可按同签名更新；老内测 `kapi.ledger.debug` 是不同应用。先在旧版导出并保留原 App，再在新版从系统文件选择器导入个人备份，核对条数和余额。不要卸载旧版后才做备份。
4. 家庭数据应连接原来的 NAS、家庭和成员身份恢复。不要把别人的家庭历史重新导入个人账本。旧内测永久权益由发行者免费发迁移码；普通备份不是 Pro 凭据。
5. Docker 下载页展示版本、SHA-256 和签名证书摘要；支持断点续传。用户 Docker 不接收发布者 API Token 或私钥。

## 爱发电方案

2026-11-02 调整定价草稿：月度 6.90 元（31 天）、年度 69 元（365 天）、终身 99 元，均不自动扣费。只从安卓入口创建购买；iOS/鸿蒙商店渠道独立处理。平台方案必须明确永久授权，禁止把按月扣款描述成买断。爱发电同一商品的三种型号已保存，保持隐藏且“可购买”关闭；月年有效期、续期、实际支付字段和退款流程尚需实现与上线验收，当前 APK 收款关闭。

## 发行者部署（不属于用户 NAS）

- `deploy/docker-compose.commerce.yml` 加 `docker-compose.commerce-live.yml` 是独立订单服务。
- 复制 `deploy/commerce.afdian.env.example` 到仅发行者可读的私有配置，保持 `COMMERCE_PAYMENTS_ENABLED=false`。
- Afdian Token 与 ECDSA 私钥放独立私有目录，文件权限 0600。不得提交 Git、上传 Release、嵌入 APK 或装入用户镜像。
- 订单服务前面需独立公网 HTTPS。只暴露订单 API；不要为收款把用户 NAS 的账本或管理端口开放到公网。当前没有配置可供公开用户访问的订单服务地址。
- Webhook 地址为 `https://发行者域名/v1/commerce/notify/afdian`。API Token 查询仅向 `https://afdian.com/api/open/query-order` 发送签名请求。

### 发布者只读检查

私有环境配置加载后，在 `kapi-sync` 中运行 `go run ./cmd/kapi-commerce -check-afdian`。该命令使用正式签名查询接口，仅输出认证结果与第一页数量，不打开订单库、不创建订单、不发放权益。错误输出不包含平台原文、密钥、付款人或订单号。2026-11-02 已连接真实接口通过；这不等于真实购买验收。

官方创作者主页为 https://afdian.com/a/guizhangapp 。已使用本仓库提交创作者认证，尚在等待平台处理。商品隐藏并关闭购买，公开 HTTPS 订单服务尚未部署，Webhook 尚未配置，不应引导用户付款。

## 新价格的上线门禁

- 新价格单独使用 `pricing` 版本 2，月度／年度／终身采用三个新产品标识；旧 `product` 和 29.90 元常量仅用于旧凭据核验，权益迁移版本仍为 1。
- `pricing.checkout_ready=false`，发布者程序拒绝以 `COMMERCE_PAYMENTS_ENABLED=true` 启动；已有订单仍可在关闭收款的状态下查询恢复。
- 当前只完成新价格定义与展示，不能把月度或年度购买送入旧永久授权流程。
- 后续需实现按已核验付款时间签发到期日、续期叠加、单笔退款回收、重复通知幂等、换机恢复与防状态回退；终身购买和内测赠送不被限时权益覆盖。
- 到期不删除或锁住已有账单、家庭记录、现金余额、导出或基础同步。
- GitHub 现有 Android 0.1.172 / NAS 0.5.9 发布附件保持原样；本次未发布新二进制或升级用户实例。

## 核验和恢复

以下为此前永久版的已实现订单机制；新三档尚未用于真实收款。订单先落盘，再跳转官方爱发电 checkout，携带归账内部订单号。付款返回仅触发查询，不直接给权益。服务端查验方案、实际已付金额、SKU／数量、支付状态和对应订单后发 GZO1 签名回执；客户端核对随机挑战与单调版本。重复通知、重复点击、创建响应丢失都复用原订单，不写账本。

通知丢失时自动查近 150 笔；更早的订单可输入爱发电订单号精确查询，但仍必须提供原购买凭据并匹配内部订单号，不能拿他人订单号激活。换机前保存 GZB1 购买凭据，勿公开分享。NAS 可使用同一凭据在线核验恢复；断网不清除已有权益。

平台公开文档只定义成功订单通知，本版不伪造自动退款状态。发行者完成平台真实退款、核对订单与金额后，停独立订单服务并执行本地 `-record-afdian-refund-order <归账订单号> -refund-reference <实际退款编号> -refund-minor 2990`，再启动服务。该命令只记录已发生退款，不转账。安卓下次联网核验失效；NAS 目前在再次核对购买凭据时更新，尚未自动定时查询退款。

## 验收边界

隔离签名和模拟平台测试不等于真实付款。正式开放前必须核验一次真实购买、官方回传字段、退款、重装恢复与密钥保管。无论免费、Pro 或退款，已有账单、家庭、导出和现金余额应保留。

## 部署与离线导出

`ghcr.io/hongjiahao371-pixel/kapi-nas:0.5.9` 已完成匿名完整层下载和哈希核验，可直接通过 Compose 拉取。NAS Release 提供 Compose、环境变量示例和证书初始化脚本；不是账本备份，不包含私钥或账户令牌。当前镜像对 Linux amd64 做过独立容器验收。

对应 Actions 产物额外导出离线镜像，下载可能要求 GitHub 登录。Release 本身不包含离线镜像；尚未完成离线导入的实际验收。网络通畅时优先使用上述公开镜像。

爱发电开通必须从安卓 App 发起，以便绑定订单和购买凭据。单独在主页赞助不会自动获得绑定权益，正式方案发布前会明确说明，避免用户误付。
