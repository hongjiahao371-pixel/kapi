# NAS / Docker 0.5.4

本次发布包含：电脑账单导入（CSV/TSV/XLS/XLSX/PDF/ZIP）、错误行修正、列与分类映射、重复候选、分类明细、金额/分类/账户/备注编辑及手机同步，账户与投资查询，个人与家庭空间隔离，HTTPS、鉴权失败限流、令牌存储与浏览器防护。

已在真实 x86-64 NAS 部署，并在 OPPO/realme 正式客户端完成 HTTPS 配置和重复同步。家庭多成员、空间隔离、编辑权限、导入与四字段编辑往返另在真实 NAS 的隔离实例及 Android 内存账本验证。Go race 回归与静态检查通过。验证不包含所有浏览器、所有 NAS 架构或全部手机功能。

现成镜像平台为 linux/amd64；包含共用 JVM 导入读取器与第三方许可。不含 APK、HAP、IPA、用户账本、服务商密钥、私有证书或生产配置。旧 HTTP 保持兼容，不代表所有客户端都已加密。

重要边界：Android/NAS 已有家庭功能，iOS/鸿蒙尚未加入同一轮家庭接入验收；行情服务仍需合法数据源配置；含糊的转账、还款、投资、退款流水保留人工核对，不能全部视作消费。

公开镜像：`jvsheng/guizhang:0.5.4`，`latest` 同步指向该版本。Docker Hub 镜像补充了项目非商业协议和来源标签，应用与依赖层沿用已验收版本。离线镜像的摘要与 Hub manifest 摘要不是同一项，不可混用；详见部署说明。
