# NAS / Docker 0.5.5

增加收入结构分析：点击首页收入或在统计中切换“收入构成”，查看各分类的金额、占比和笔数；点击分类进入账单明细及单笔详情。日期、账本等筛选继续生效。

## 数据与兼容性

- 只增加 `by_income_category` 和 `income_category` 只读统计 / 查询能力，不迁移数据库、不生成同步账单、不修改手机数据格式。
- 收入分类与收入合计口径一致。有效关联退款抵扣原支出；账户划转和已删除账单不计收入构成；未分类收入单独显示。未关联原账单的历史退款保持原统计口径，不自动改账。
- 家庭共享、成员私有空间的鉴权和成员本人编辑权限保持不变。
- 不更新本次发布范围外的移动端和账单导入读取规则。

## 部署

公开镜像：`jvsheng/guizhang:0.5.5`；`latest` 指向同一发布内容。当前现成镜像仅验收 `linux/amd64`（x86-64 NAS）。

原 HTTP、HTTPS 完整配置和 Compose 叠加配置已同步更新，参见 [部署说明](DEPLOYMENT.md)。保留原 `data/`、`.env`、`tls/`、容器名与空间 URL；停机备份后仅切换镜像，禁止用空数据目录替换原账本或重新配对。

GitHub Release 提供离线镜像、部署 ZIP 和 SHA256SUMS。包内不含真实账单、配对凭据、令牌或 TLS 私钥，继续采用 PolyForm Noncommercial 1.0.0，第三方许可保持原样。

## 验证范围

收入分类、下钻与金额对账、退款 / 划转 / 删除 / 未分类边界、筛选分页、HTTP 鉴权和家庭空间隔离有自动回归；网页实际验证收入入口、分类明细、单笔详情及返回，并回归支出和退款。发布包还验证空数据安装、真实 NAS 快照升级、HTTPS、家庭配置和旧日志保留。回滚仅恢复镜像及运行配置，保留升级后新写入，不回灌旧数据。
