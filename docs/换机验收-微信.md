## 1. 安装与权限（顺序不能反）

APK：`kapi-android/app/build/outputs/apk/debug/app-debug.apk`（包名 kapi.ledger.debug，全流程已含今天支付宝侧的全部修复）

```bash
# ① 先装包（install -r / force-stop 都会清掉无障碍授权，所以先装后开）
adb install -r kapi-android/app/build/outputs/apk/debug/app-debug.apk
# ② 打开 App 一次（铺种子账户/分类，跑 ensureSeeded）
adb shell monkey -p kapi.ledger.debug -c android.intent.category.LAUNCHER 1
# ③ 授权无障碍（<其它服务列表> 为空就只写 kapi 自己）
adb shell "settings put secure enabled_accessibility_services 'kapi.ledger.debug/kapi.ledger.auto.KapiAccessibilityService:com.google.android.accessibility.switchaccess/com.android.switchaccess.SwitchAccessService'"
# ↑ SwitchAccess 必须保留：微信只在受信任读屏服务绑定时才建节点树（它第一次
#   启用会弹设置向导和权限框，跟着点完即可；平时关掉向导不影响绑定）
adb shell "settings put secure accessibility_enabled 1"
# ④ 确认服务真的绑上了（在列表里 ≠ 绑定成功）
adb shell dumpsys accessibility | grep -A 3 "Enabled services"
adb logcat -d | grep 无障碍服务已连接 | tail -1
```

验证期间**不要** `am force-stop` 任何东西（会把自己刚开的权限拆掉）。

## 2. 可读性探针（1 分钟，技术检查不是目的）

```bash
tools/probe-a11y.sh com.tencent.mm/.ui.LauncherUI
```

  realme 上实测过的现象）；**先告诉用户，再决定是换一台还是 OCR 立项**

## 5. 已知差异与坑（开扫前读一遍）

- 微信与支付宝树序可能不同：微信详情页「值在标签前」，支付宝富账单页
  「值在后」。ScreenFields 靠日期行探方向；微信**没有时间字段名**时探针
  落空，退回先上一行后下一行——方向判反就抓「原始行序」日志看真实树序。
- 新机微信版本若高于 8.0.78，页面结构可能变——出现新缺陷属正常。
- 验包：versionCode 按天递增，同天分不出——用 dex 特征串
  （`自转账：`/`形状像一笔`，utf8 解码 + 带对照串），见 微信读屏方案.md 第 7 节。
